# Свидетельства проверки 003

PNG получены из настоящего HTML5-рендера Chromium через Playwright, а не сгенерированы по тексту. Команды и итоговые ограничения — в `docs/design/003-first-level-visual-upgrade.md`.

- `003-<width>x<height>.png`: игра после первого шага, пять размеров viewport.
- `003-light-*.png`: отдельная диагностическая сцена радиального света на равномерном полу. Стены дополнительно проверяются выборками пикселей в тесте.
- `003-victory.png`: состояние после прохождения маршрута из 36 шагов.
- `003-hero-*.png`: направления героя, для художественной проверки.
- `003-first.png`: промежуточный портретный кадр разработки.

Снимки не доказывают частоту кадров, слышимость звука или работу на физическом телефоне. Повторный запуск тестов обновляет PNG.
