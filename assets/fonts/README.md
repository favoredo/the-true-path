# Шрифты

Шрифты хранятся локально и включаются в сборку Defold. Во время игры загрузок с CDN нет. Лицензии SIL Open Font License находятся рядом с файлами.

- Noto Sans Regular: https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf ; лицензия: https://github.com/notofonts/noto-fonts/blob/main/LICENSE
- Libre Baskerville: https://github.com/google/fonts/blob/main/ofl/librebaskerville/LibreBaskerville%5Bwght%5D.ttf ; лицензия: https://github.com/google/fonts/blob/main/ofl/librebaskerville/OFL.txt

Дата получения: 2026-09-13. `LibreBaskerville-Regular.ttf` — локальное имя исходного вариативного файла; Defold использует его начертание по умолчанию. Изменений контуров шрифта не производилось.
