## Требования, использованные при генерации

Ниже краткое описание задания, не дословная копия промптов: книжная живописная иллюстрация, верхний ракурс, единый исследователь 36 лет с короткими русыми волосами, коричневой фетровой шляпой с поднятыми боками, кожаной курткой без капюшона, брюками, низкими полуботинками, сумкой и факелом; отдельный лист сухой земли, камня и тропической растительности без встроенного освещения и светящихся частиц.

Фактические варианты поз отличаются слабо. Финальная оценка походки и соответствия персонажа макету остаётся частью AC-9. Не считать этот лист эталоном анатомии или утверждённой пользователем финальной анимацией.
